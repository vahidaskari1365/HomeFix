# 🔧 HomeFix — پلتفرم متخصص‌های خانگی

**HomeFix** یک مارکت‌پلیس خدمات خانگی برای ایران است: مشتری سفارش ثبت می‌کند، پلتفرم بهترین متخصص را پیدا می‌کند، کار با «کد ورود» امن انجام می‌شود، پرداخت درون‌برنامه‌ای است و پلتفرم کمیسیون برمی‌دارد.

> از کولر تا لوله‌کشی — انتخاب کن، متخصص مناسب می‌رسد، با خیال راحت پرداخت کن.

## ✨ قابلیت‌ها

### سمت مشتری
- 🧭 **ویزارد ۳ مرحله‌ای سفارش**: سرویس ← زمان و آدرس ← تأیید (تاریخ شمسی، بازه‌های ساعتی)
- 🤖 **دستیار هوشمند**: توضیح مشکل را بنویسید، هوش مصنوعی سرویس مناسب را پیشنهاد می‌دهد (با fallback کلیدواژه‌ای)
- 🔎 **ردیابی زنده سفارش**: تایم‌لاین ۷ مرحله‌ای + نقشه شبیه‌سازی‌شده حرکت متخصص با ETA
- 🔐 **کد ورود یک‌بارمصرف**: ۴ رقم، فقط زمانی که متخصص جلوی در است — زمان ورود/خروج ثبت می‌شود
- 💳 **پرداخت درون‌برنامه‌ای**: درگاه بانکی یا کیف پول + نمایش شفاف تفکیک کمیسیون
- ⭐ **امتیازدهی دوطرفه** + 🚨 **دکمه اضطراری** (تماس پشتیبانی، ثبت گزارش، ارجاع به ۱۱۰/۱۲۵)
- 📋 «سفارش‌های من» با شماره موبایل

### سمت متخصص
- 📝 **ثبت‌نام ۶ مرحله‌ای**: موبایل+OTP ← اطلاعات شخصی ← تخصص‌ها ← سابقه ← مدارک (کد ملی/کارت بانکی) ← مصاحبه شبیه‌سازی‌شده
- 🟢🔵🟣 **سطوح امنیتی ۳ لایه**: هویت تأیید شده ← + مهارت تأیید شده ← + متخصص برتر (عملکرد)
- 📥 **پیشنهادهای سفارش** با پذیرش/رد (رد = ارسال خودکار به متخصص بعدی)
- 💰 **درآمد**: امروز / این ماه / کل / در انتظار تسویه
- 🟢 سوییچ آنلاین/آفلاین، نظرات دریافتی، تغییر پلن

### موتور کسب‌وکار (پلتفرم)
- 🎯 **ماچینگ خودکار**: ACTIVE + آنلاین + مهارت مرتبط، رتبه‌بندی بر اساس سطح احراز ← امتیاز ← سفارش‌های موفق
- 💸 **کمیسیون پلکانی**: ۱۰ سفارش اول **۱۰٪** ← پلن رایگان **۱۵٪** / پلن حرفه‌ای **۸٪** (۱۹۹٬۰۰۰ تومان/ماه)
- 🛡 سطوح احراز به‌صورت خودکار بعد از هر پرداخت بازمحاسبه می‌شوند (هرگز کاهش نمی‌یابند)

## 🛠 استک فنی

| لایه | تکنولوژی |
|---|---|
| فریم‌ورک | Next.js 16 (App Router) + TypeScript 5 |
| UI | Tailwind CSS 4 + shadcn/ui + lucide-react + framer-motion |
| فونت و زبان | Vazirmatn، فارسی RTL کامل، اعداد فارسی |
| دیتابیس | Prisma ORM + SQLite |
| State | Zustand (persist) + TanStack Query (polling) |
| AI | z-ai-web-dev-sdk (فقط بک‌اند) |
| سئو | Metadata کامل + JSON-LD `HomeAndConstructionBusiness` با `areaServed` (الگوی SAB از اسکیل seo-local) |

## 🚀 اجرا

```bash
bun install
bun run db:push        # ساخت جداول
bun prisma/seed.ts     # داده‌های نمونه (۸ دسته، ۲۵ سرویس، ۸ متخصص)
bun run dev            # http://localhost:3000
```

## 🧪 دموی کامل (حالت دو نقشه‌ای)

1. به‌عنوان مشتری: «ثبت درخواست» ← کولر و تهویه ← سرویس و شارژ کولر گازی ← امروز ← ۱۷ تا ۱۹
2. در صفحه پیگیری، دکمه «⚡ قبول سفارش (شبیه‌سازی متخصص)» را بزنید
3. کد ورود ۴ رقمی را یادداشت کنید
4. «پنل متخصص» ← ورود با `09121000001` (کد نمایشی OTP: `121212`)
5. در سفارش فعال، کد ورود را وارد کنید ← شروع کار ← اتمام کار
6. به‌عنوان مشتری پرداخت کنید و امتیاز دهید ⭐

**متخصص‌های نمونه:** `09121000001` محمد رضایی (پلن حرفه‌ای، سطح ۳) … `09121000008`
